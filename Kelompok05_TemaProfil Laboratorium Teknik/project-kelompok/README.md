- `galeri.html` : Galeri foto laboratorium
- `data.html` : Tabel fasilitas/peralatan dan jadwal praktikum

---

## Cara Menjalankan

1. Ekstrak file zip.
2. Buka file `index.html` dengan browser (Chrome/Edge/Firefox).
3. Tidak perlu instalasi atau konfigurasi tambahan.
4. Untuk menguji responsive: tekan `F12`, lalu `Ctrl+Shift+M`.
